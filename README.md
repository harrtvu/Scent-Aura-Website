# Scent Aura

A hand-poured scented candle shopfront for **Scent Aura** — quiet rooms, lasting fragrance, and a calm shopping experience.

## Stack

- Vite
- React 19 + TypeScript
- CSS (custom properties, responsive layout)

## Scripts

```bash
npm install
npm run dev
npm run build
npm run preview
```

## Features

- Brand-first full-bleed hero
- Six-scent product collection with add-to-bag
- Sliding shopping bag with quantity controls
- Ritual and atelier story sections
- Responsive layout for mobile and desktop
